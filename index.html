⚡ 30 秒白話懶人包：日矽案到底在演什麼？

👑 日月光（進攻方）：全球封測老大，手頭很多錢。2015 年開價每股 45 元（送 34% 溢價）直接突襲收購矽品。

🛡️ 矽品（防守方）：很會賺錢，但經營層股票不到 5%，近 60% 都是外資。急著找鴻海換股、紫光私募印股票擋，被重視獲利的外資股東投票封殺。

🤝 大和解：吵了三年，最後合組「日月光投資控股公司」，兩家變成平起平坐的兄弟公司，外資拿錢退場、矽品老闆繼續管矽品，一起對抗台積電與紅色供應鏈。

📊 課本第一章「四大財務功能」白話對照表
財務維度 課本定義（白話） 日月光具體做法 矽品具體做法
1. 資金的投資 買現成比自己蓋快 花錢收購矽品，不用重複花幾百億買機台，直接買下現成產能與頂級客戶。 評估單獨對抗台積電先進封裝與中國長電，獨立投資 CapEx 風險過高。
2. 資金的募集 銀行借錢 vs 亂印股票 向銀行聯貸數百億＋控股換股，妥善調配負債與權益比率。 想印新股票給鴻海跟紫光來稀釋對手，被外資痛罵稀釋舊股東每股價值。
3. 資金的管理 停止自殘、機台互調 兩家機台與原物料互通，降低流動資金壓力與重複開模浪費。 終止與日月光搶訂單比誰賒帳久（放寬帳期）的惡性競爭，現金流改善。
4. 股利的分配 高配息的雙面刃 投控成立後，維持穩健發放股利同時保留足額現金研發先進製程。 過去年年高配息吸引 60% 外資，但在收購戰中外資只挺出高價者，反噬經營層。

🍎 為什麼 Safari 顯示不支援 WebGPU？

這是 Apple 的預設限制！蘋果在 Safari 中將 WebGPU 歸類為實驗功能，因此預設關閉。

💡 最無腦解法（強烈推薦）：
請直接複製本網址，改用 Google Chrome 或 Microsoft Edge 打開，點擊即可直接執行 Gemma 4-E2B 助教，無需任何設定！

如果你一定要在 Safari 使用，請依以下步驟開啟：

  • Mac Safari：點左上角 Safari -> 設定 -> 進階 -> 勾選「為網頁開發者顯示功能」-> 上方「開發」選單 -> 功能旗標 (Feature Flags) -> 搜尋並勾選 WebGPU。
  • iPhone / iPad：打開「設定」->「Safari」-> 滑到最底「進階」->「功能旗標」-> 找到 WebGPU 並開啟。
操作成功！

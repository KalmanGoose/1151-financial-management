# 財務管理作業工作流 (Academic Workflow)

本目錄已統一規範為作業模組化結構，所有作業皆收攏於 `HOMEWORK/` 目錄中。

---

## 專案目錄結構

```text
.
├── ACADEMIC_AGENT.md        # 系統提示詞協定（定義 AI 助理的角色與學術守則）
├── ASSIGNMENT_TEMPLATE.md   # 標準作業 Markdown 模板（內建 AI 歷程自主揭露表）
├── README.md                # 專案導覽說明
└── HOMEWORK/                # 所有學期作業統一存放區
    ├── HW1/                 # 作業 1：日矽案與財務管理導論
    │   ├── 01_PROMPT/       # 題目、課綱、課本重點與個案背景
    │   ├── 02_AGENT_COLLAB/ # AI 協同大綱、白話推論矩陣與四人視角
    │   ├── 03_DRAFT/        # 四人組員正文草稿
    │   ├── 04_FINAL_OUTPUT/ # 定稿與繳交版
    │   └── HW1_日矽案_四人小組討論手冊.html # 小組好讀網頁手冊
    ├── HW2/                 # 作業 2（預先建立好 4 步驟工作流）
    └── HW3/                 # 作業 3（預先建立好 4 步驟工作流）
```
